## Code Review

### CS 499 Milestone One: Inventory Management Application

As part of my CS 499 Computer Science Capstone at Southern
New Hampshire University, I conducted a code review of an
Inventory Management Application that I originally developed
in CS 360: Mobile Architecture and Programming.

The code review examines the application's existing
functionality, identifies areas for improvement, and explains
the enhancements planned for three computer science categories:

- **Software Design and Engineering:** Improving application
  functionality, input validation, and user interface design.

- **Algorithms and Data Structures:** Implementing inventory
  searching, sorting, and expiration-date calculations.

- **Databases:** Improving database functionality, data
  integrity, and security.

The review also discusses how these improvements relate to
the CS 499 course outcomes and demonstrate my growth as a
computer science student.
